# Public Engineering Positioning Roadmap

This repository is the public front door for CasterlyGit. It organizes
documentation and presentation work; it does not change account settings,
repository ownership, visibility, or project status.

## Guiding standard

Every public statement must be supportable by the linked repository's source,
tests, or reproducible documentation. When evidence is incomplete, describe the
work conservatively or omit the claim.

## Backlog rules

- Create an issue before substantive public documentation or repository work.
- Use a focused branch and pull request for each coherent change.
- Record validation commands and any known gaps in the pull request.
- Never include private recruiting, application, contact, employment, or work
  authorization information in this public repository.
- Do not archive, rename, transfer, change visibility, or change ownership
  without an explicit owner decision.
